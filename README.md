# AI Transaction Anomaly Detection

An AI-based project that detects unusual or suspicious transactions using the Isolation Forest machine learning algorithm.

## Project Overview

This project analyzes transaction data and identifies abnormal transaction patterns based on features such as transaction amount, transaction frequency, and night-time transactions.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Isolation Forest
- Google Colab

## Features

- Transaction data analysis
- Missing value checking
- Feature selection
- Anomaly detection
- Identification of normal and unusual transactions

## Machine Learning Algorithm

### Isolation Forest

Isolation Forest is an unsupervised machine learning algorithm used to detect anomalies or unusual data points.

## Project Workflow

1. Create and load transaction data
2. Check for missing values
3. Select important features
4. Train the Isolation Forest model
5. Detect anomalies
6. Analyze the results

## How to Run

Open the `.ipynb` notebook in Google Colab and run the cells sequentially.
